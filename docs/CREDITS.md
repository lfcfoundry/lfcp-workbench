# Credits

LFCP Workbench borrows ideas from other projects and papers. Where an optimized part uses such an idea, the part lives in its own file (or clearly marked section) and its header names the source. The code is our own implementation; no code was copied from the projects below, except the four WebAssembly decoders named in the last rows, which are built from their original sources and carry their licenses. If a credit here is wrong or missing, please open an issue.

| Our part | Where | Idea from | Original authors and project |
|---|---|---|---|
| Top-N sort: keep the best k rows with one comparison per row | [`src/query/topn.mjs`](../src/query/topn.mjs) | Bounded-heap "TopN" operator | DuckDB: Mark Raasveldt, Hannes Muehleisen and the DuckDB contributors ([duckdb.org](https://duckdb.org/)); the technique itself is the textbook top-k heap selection |
| Skip whole blocks that cannot hold a top-N row (per-block minimum and maximum) | [`src/query/topn.mjs`](../src/query/topn.mjs) | Zone maps, "Small Materialized Aggregates" | Guido Moerkotte, VLDB 1998 ([paper](http://www.vldb.org/conf/1998/p476.pdf)); also in Apache Parquet row-group statistics ([Parquet format](https://parquet.apache.org/docs/file-format/)) and DuckDB row-group statistics |
| Typed decimals: a decimal cell stored as a whole number scaled by 10^d, text kept when not exact | [`src/ingest/infer.mjs`](../src/ingest/infer.mjs) (`typedDecimal`, `sampleDecimals`, `formatScaled`), [`src/query/query.mjs`](../src/query/query.mjs) | Fixed-point DECIMAL columns | Apache Parquet DECIMAL logical type ([spec](https://parquet.apache.org/docs/file-format/types/logicaltypes/)); DuckDB DECIMAL ([docs](https://duckdb.org/docs/stable/sql/data_types/numeric)) |
| One-of filter `=a\|b` | [`src/query/query.mjs`](../src/query/query.mjs), [`src/query/positions.mjs`](../src/query/positions.mjs) | SQL `IN (...)` list tested with a hash set | ISO SQL; see DuckDB's [IN operator](https://duckdb.org/docs/stable/sql/expressions/in); LFC-pack's own `anyOf` row-number query does the work on columns not decoded yet |
| Staged columns: CSV bytes straight to typed column chunks (numbers as 64-bit values, text as byte offsets into one buffer), no row text | [`src/ingest/columns.mjs`](../src/ingest/columns.mjs), [`src/ingest/colbuild.mjs`](../src/ingest/colbuild.mjs), [`wasm/colbuild.c`](../wasm/colbuild.c) | Columnar in-memory layout with offset-pair "variable-size binary" text; CSV readers that fill column vectors directly | Apache Arrow ([columnar format](https://arrow.apache.org/docs/format/Columnar.html)); DuckDB's CSV reader ([duckdb.org](https://duckdb.org/)) |
| Dictionary columns: low-variety text columns built as a small code per row plus the distinct values, packed from the codes | [`wasm/colbuild.c`](../wasm/colbuild.c), [`src/ingest/colbuild.mjs`](../src/ingest/colbuild.mjs), `app/worker.js` | Dictionary-encoded columns (distinct values stored once, rows hold indices); first wasm version by the parse-research thread of this project | Apache Arrow ([dictionary encoding](https://arrow.apache.org/docs/format/Columnar.html#dictionary-encoded-layout)); Apache Parquet ([dictionary encoding](https://parquet.apache.org/docs/file-format/data-pages/encodings/)) |
| Wasm row builder (when shipped) | `app/worker.js` | Compiling a small C routine to WebAssembly (SIMD) | [WebAssembly](https://webassembly.org/) community group; [LLVM / clang](https://llvm.org/) |
| Compression, row numbers, zone ranges | `vendor/lfcp/` | LFC-pack | LFC Foundry; zstd by Yann Collet and Meta ([zstd](https://facebook.github.io/zstd/)), see [`vendor/lfcp/0.10.28/NOTICE-zstd.txt`](../vendor/lfcp/0.10.28/NOTICE-zstd.txt) |
| Parquet and Arrow page decoders (GZIP, BROTLI, LZ4, ZSTD) | `app/worker.js` (wasm in base64), [`docs/NOTICES-WASM-DECODERS.txt`](NOTICES-WASM-DECODERS.txt) | Decoders built to WebAssembly: libdeflate (GZIP), Google's brotli reference decoder (BROTLI, loaded only when needed), zstd (ZSTD); LZ4 is our own decoder written from the public block format | [libdeflate](https://github.com/ebiggers/libdeflate) by Eric Biggers (MIT, [license](https://raw.githubusercontent.com/ebiggers/libdeflate/master/COPYING)); [brotli](https://github.com/google/brotli) by the Brotli Authors (MIT, [license](https://raw.githubusercontent.com/google/brotli/master/LICENSE)); [zstd](https://github.com/facebook/zstd) by Yann Collet and Meta (BSD-3-Clause, [license](https://raw.githubusercontent.com/facebook/zstd/dev/LICENSE)); [LZ4 block format](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md) by Yann Collet; [Parquet compression spec](https://github.com/apache/parquet-format/blob/master/Compression.md) |

Rivals we measure against (no code used): DuckDB-WASM, SQLite-WASM, Arquero, Papa Parse, Perspective, Glide Data Grid. Each results file records the exact versions tested.
