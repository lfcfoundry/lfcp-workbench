# Whole-import tester
Unlisted, noindex. tester.html compares two Workbench builds on the same files, three runs each, alternating order: `before` (79e8a32, before the Parquet pool and pack-worker changes) and `after` (main fa38874, PR 92). Part A: Parquet files you pick (taxi, SBA 1-group, SBA 3-group). Part B: a CSV import plus the first and repeat Save (synthetic taxi-shaped CSV made in the page, or your own file; a made-up 116-column CSV from wide-csv-generator.mjs or your own wide file). Part C: parse-helper sweep (internal `parseHelpers` option, 2/3/4/6) with 1 and 3 pack workers, after build only. Prints import ms, stored bytes, Save ms and the timing JSON; Copy results button. Everything stays in the browser.
