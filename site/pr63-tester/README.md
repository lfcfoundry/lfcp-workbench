# PR 63 JSON overhead tester
tester.html times the Workbench before PR 63 (before/, commit 880d5c6) and after (after/, main 1e8f3f7) importing the same synthetic taxi-shaped NDJSON and JSON array (400,000 rows, about 169 MB each, made in the page). Order before, after, after, before, twice per format. Progress panel, Copy results button. Needs http(s): web workers do not start from a saved file, so it must be served (for example as an unlisted Pages file with before/ and after/ beside it). Local test: Chromium 156 full size ran clean; 20,000-row smoke test ran clean in Chromium and Firefox 158. Add ?rows=N for a smaller run.
